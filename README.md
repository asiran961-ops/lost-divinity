# 《신위록》 홈페이지 · GitHub Pages 배포용 파일

정리된 파일을 GitHub 저장소 루트에 업로드하세요. 이미지 74장과 BGM 1개 포함.

`index.html` `characters.html` `styles.css` `assets/` 폴더가 같은 루트에 있어야 합니다.

**주의**: 이번 번들은 기존 홈페이지의 원형을 유지한 GitHub 이전용 파일이며, 승명교 인물록 4인·자유 시작·지도 이동 기능 등 대형 업데이트 기능은 아직 구현하지 않았습니다.

`assets/images/map/world-map-revealed.webp`는 암운 지형 공개 이미지로 연결되어 있습니다. 인물 지도 마커는 기존 원본 대신 대응되는 정사각형 이미지를 재사용합니다.
